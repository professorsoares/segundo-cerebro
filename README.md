# Segundo cérebro

Fonte única da verdade para tarefas, comunicações, decisões e alinhamentos.
Markdown em git. Sem app proprietário, sem fornecedor no caminho.

## Como funciona

```
         ditado/texto no Claude          leitura e edição à mão
                   │                              │
                   ▼                              ▼
  ┌──────────────────────────────────────────────────────────┐
  │   markdown neste repositório  ← A VERDADE                │
  │   tarefas.md · decisoes.md · projetos/ · pessoas/        │
  └──────────────────────────────────────────────────────────┘
                   │                              │
                   ▼                              ▼
          painel/dados.json              brief diário por e-mail
           (gerado, read-only)            revisão sexta e segunda
```

## Os três arquivos que importam

- **`tarefas.md`** — tudo que está em aberto. Se não está aqui, não existe.
- **`decisoes.md`** — o que foi combinado, com quem e quando. Nunca se apaga linha.
- **`projetos/`** — uma frente de trabalho por arquivo, com o próximo passo concreto.

## Como usar no dia a dia

| Situação | O que fazer |
|---|---|
| Saiu de uma call com 5 pendências | Dita tudo para o Claude, cru. Ele distribui e commita. |
| Está no celular e lembrou de algo | Dita no app do Claude, ou escreve direto em `inbox/` pelo Obsidian. |
| Quer saber o que fazer agora | Lê `tarefas.md`, seção *Esta semana*, ou abre o painel. |
| Precisa saber o que foi combinado | `decisoes.md`. |
| Vai falar com alguém | `pessoas/<nome>.md` — o que ela te deve e o que você deve a ela. |

O manual de operação para o Claude está em [`CLAUDE.md`](CLAUDE.md).
Para abrir no Obsidian: *Open folder as vault* → esta pasta.
