# Inbox

Captura crua. Jogue tudo aqui sem organizar — texto, áudio ditado, print de
conversa, pensamento solto. Um arquivo por captura: `AAAA-MM-DD-slug.md`.

**Esta pasta deve tender a zero.** O Claude processa, distribui para
`tarefas.md` / `projetos/` / `decisoes.md` / `pessoas/` e apaga o item daqui.

Se tem coisa velha encalhada aqui, o sistema não está sendo processado.
